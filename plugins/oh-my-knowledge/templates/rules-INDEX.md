Link notation used in these rules: `[[g:slug]]` = `<knowledge base>/global/<slug>.md`, `[[k:<relpath>]]` = `<knowledge base>/<relpath>.md` (knowledge base = the folder that contains this `rules/` folder).

# Rules

Each rule file in this folder is loaded by importing it here, one include per line in the form `@[label](path)` with a path relative to this file (for example `@[my-rule](my-rule.md)`). Add a line when you add a rule; remove it when the rule is retired.
